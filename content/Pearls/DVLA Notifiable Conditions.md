Patients need to notify the DVLA themselves, but if they refuse to do so doctors can break confidentiality

| Condition/Note                       | Group 1 Details                            | Group 2 Details                                  |
| :----------------------------------- | :----------------------------------------- | :----------------------------------------------- |
| **Epilepsy**                         | Seizure 12 months                          | Can't drive                                      |
| **TIA (Transient Ischaemic Attack)** | 1 month; depends on recovery               | Can't drive; notify DVLA; may re-license         |
| **Angina**                           | Depends on symptoms                        | Stop; 6 weeks symptom free                       |
| **ACS (Acute Coronary Syndrome)**    | Stop 1-4 weeks                             | Stop; DVLA reassess 6/52                         |
| **HF (Heart Failure)**               | NYHA class 4 can't drive                   | EF <40% or NYHF 3                                |
| **AF (Atrial Fibrillation)**         | Only if incapacitating                     | Stop; notify DVLA                                |
| **Diabetes**                         | Multiple hypoglycaemia; regular BM testing | Main risks around hypoglycaemia, insulin, vision |

## Neurology

| Pathology                                                     | DVLA                                                       |
| ------------------------------------------------------------- | ---------------------------------------------------------- |
| [[Full/Stroke\|Stroke]]                                       | Cease for 1 month; resume only in minimal residual deficit |
| [[Full/Transient Ischemic Attack\|Transient Ischemic Attack]] | Cease for 1 month                                          |
| [[Pearls/Meningitis\|Meningitis]]                             | Drive if well                                              |
| First [[Pearls/Epilepsy\|seizure]]                            | Cease for 6 months                                         |
| Severe head injury/<br>intra-cranial bleed                    | Cease for 6-12 months                                      |
| [[Pearls/Brain tumours\|Brain tumours]] mets                  | Variable - patient reports to DVLA                         |
| Neurosurgery                                                  | "                                                          |
| Visual field defects & diplopia                               | Cease driving                                              |
| Visual acuity                                                 | Must be better than 6/12                                   |
| Unexplained syncope                                           | Cease 4 weeks if low risk else 6 months                    |
| Recurrent severe vertigo                                      | Once attacks controlled                                    |

## Diabetes

| Pathology                               | DVLA                                                                                              |
| --------------------------------------- | ------------------------------------------------------------------------------------------------- |
| On insulin or oral hypoglycaemic agents | Must be able to recognise hypo and not had >1 hypo requiring assistance within the past 12 months |
| Recurrent hypoglycaemia                 | Cease until controlled                                                                            |

## Cardiovascular 

| Pathology                                                                                                       | DVLA                                                     |
| --------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| Angina                                                                                                          | Cease until stable                                       |
| [[Full/myocardial infarction\|myocardial infarction]]/[[Full/Acute Coronary Syndrome\|Acute Coronary Syndrome]] | Cease for 1 week if successful angioplasty, else 4 weeks |
| Angioplasty                                                                                                     | Cease for 1 week                                         |
| Pacemaker                                                                                                       | Cease for 1 week                                         |
| ICD (if inserted after incapacitation)                                                                          | Cease for 6 months                                       |
| ICD (if inserted prophylactically)                                                                              | Cease for 1 month                                        |
| CABG                                                                                                            | Cease for 1 month                                        |
| Incapacitating arrhythmia                                                                                       | Cease until controlled + 1 month                         |
| AAA                                                                                                             | If > 6.5cm cease until repaired                          |
| Aortic stenosis                                                                                                 | Cease if symptomatic                                     |

## Psychiatry and substance

| Pathology                           | DVLA                                  |
| ----------------------------------- | ------------------------------------- |
| Severe psychiatric illness          | Cease until stable + 3 months         |
| Alcohol dependance                  | Cease until 1 year abstinence         |
| Opioid, benzo or cocaine dependance | Cease until 1 year after previous use |
| Other recreational use              | Cease for 6 months after previous     |

## Other

| Chronic renal failure                        | Drive if well                              |
