## Secretions:

| What | Source |
| --- | --- |
| Bile salts | Liver |
| Bicarbonate ions | Pancreas |
| Trypsin, chymotrypsin, carboxypeptidase | Pancreas |
| Lipase | Pancreas |
| Pancreatic amylase | Pancreas |
| Nucleases | Pancreas |
| Mucus | Goblet cells |
| Peptidases | Small intestine |
| Sucrase, lactase, maltase | Small intestine |
