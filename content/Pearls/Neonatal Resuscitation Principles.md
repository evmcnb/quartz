Need to increase oxygenation via positive pressure ventilation (bag valve mask or ET)

- Oxygen is a potent vasodilator. If there are still issues pulmonary vasoconstriction can try inhaled nitric oxide
- Fluid bolus can cause ionotropic effect + actual ionotropes can help pulmonary perfusion
