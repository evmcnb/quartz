## Causes

|                          |                                                                                                                                                                                |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Medications**          | ACEis  <br>ARBs  <br>Potassium sparing diuretics  <br>Trimethoprim  <br>Beta blockers  <br>Suxamethonium                                                                       |
| **Acute Conditions**     | AKI  <br>Metabolic acidosis  <br>Rhabdomyolysis  <br>[[Full/Tumour lysis syndrome\|Tumour lysis syndrome]] <br>Burns  <br>Hypoaldosteronism <br>Type IV renal tubular acidosis |
| **Pseudo-hyperkalaemia** | Test tube haemolyiss  <br>Prolonged tourniquet time  <br>Marked leucocytosis haemolysis  <br>Drip arm sample                                                                   |

* Treat if 6.5 mmol/L or if any ECG changes
* Widening QRS, tall tented [[Pearls/T waves|T waves]], prolonged PR, flattened P waves

* [[Pearls/Insulin|Insulin]] - drives potassium from extracellular space in
* Dextrose to prevent [[Full/Hypoglycaemia]] when [[Pearls/Insulin|Insulin]] is given
* Calcium gluconate - stabilised the cardiac membrane
