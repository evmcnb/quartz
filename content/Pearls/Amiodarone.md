| **Drug Class**         | Anti-dysrhythmic (Class III)                                                                                                                                                                                                                                               |                                                                                                                              |                                                                                                                      |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **Mechanism**          | Prolongs refractory period in all parts of conduction system - ↓ speed of conduction through the heart                                                                                                                                                                     |                                                                                                                              |                                                                                                                      |
| **Typical Dose**       | 200-300mg                                                                                                                                                                                                                                                                  |                                                                                                                              |                                                                                                                      |
| **Indications**        | Supraventricular/ventricular [[MLA/Arrhythmias]] - esp when other drugs are contra-indicated or failed  V fib or pulseless VT refractory to defibrillation                                                                                                                     |                                                                                                                              |                                                                                                                      |
| **Contra-indications** | * Sinus bradycardia * SA block * Sinus node dysfunction * Thyroid dysfunction * Iodine sensitivity (contains iodine) * [[MLA/Pregnancy]]/breast feeding                                                                                                                        |                                                                                                                              |                                                                                                                      |
| **Side-effects**       | - Nausea/vomiting<br>- $\uparrow$ QTc<br>- [[Pearls/Jaundice\|Jaundice]]<br>- [[MLA/Hyperthyroidism\|Hyperthyroidism]]<br>- Sleep disturbances<br>- [[MLA/Pulmonary Fibrosis\|Pulmonary Fibrosis]]<br>- Corneal opacities<br>- [[MLA/Optic neuritis\|Optic neuritis]] |                                                                                                                              | Hyperthyroidism]] * Sleep disturbances * [[MLA/Pulmonary Fibrosis]] * Corneal opacities and [[MLA/Optic neuritis]]           |
| **Interactions**       | * Beta blockers: ↑ risk of bradycardia/AV block/myocardial [[MLA/Depression]] * [[snippets/Digoxin                                                                                                                                                                             | Digoxin]]: increased risk of toxicity (can be used for the same thing, so not sure when to give both) * [[snippets/Diltiazem | Diltiazem]]/verapamil: ↑ risk of bradycardia/AV block/myocardial [[MLA/Depression]] (can also be used for cardioversion) |
| **Elimination**        |                                                                                                                                                                                                                                                                            |                                                                                                                              |                                                                                                                      |
| **Additional Notes**   | ½ life of 36 days - interactions can occur after stopping treatment. Monitor thyroid, liver and lung function every 6 months                                                                                                                                               |                                                                                                                              |                                                                                                                      |
