| **Drug Class** | Stimulant laxative |
| --- | --- |
| **Mechanism** | Hydrolysed in colon to stimulate myenteric plexus, smooth muscle activity |
| **Typical Dose** | 7.5-15mg OD taken at bedtime. Max 30mg |
| **Indications** | Constipation |
| **Contra-indications** | Intestinal obstruction |
| **Side-effects** | Common: abdominal cramps/diarrhoea  Rarely: hypokalaemia (prolonged use), colonic atony |
| **Interactions** | None |
| **Elimination** |  |
| **Additional Notes** | Single dose usually produces effect in 8 hours. Prolonged use can lead to tolerance |
