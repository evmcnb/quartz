X-linked pattern. Males who inherit the affected X chromosome will inherit the condition. Females with one affected X chromosome and an unaffected X chromosome may also be affected, although the severity and features can vary.

Caused by a CGG trinucleotide repeat expansion on the X chromosome. Shows anticipation similar to [[Pearls/Huntington's Disease|Huntington's Disease]]

### Features

- Learning difficulties
- Large low set ears, long thing face, high arched palate
- Macroorchidism 
- Macrocephaly
- Hypotonia
- Autism is more common
- [[Pearls/Mitral valve disease|Mitral valve prolapse]]

Diagnosis  
- can be made antenatally by chorionic villus sampling or amniocentesis
- analysis of the number of CGG repeats using restriction endonuclease digestion and Southern blot analysis
