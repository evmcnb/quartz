| **Drug Class** | Anti-platelet agent |
| --- | --- |
| **Mechanism** | Irreversibly to the platelet P2Y12 receptor, inhibiting ADP-mediated platelet activation and aggregation |
| **Typical Dose** | 75mg OD or 300mg loading dose |
| **Indications** | * Secondary prevention of atherosclerotic events * Prior to PCI to prevent atherothrombotic events |
| **Contra-indications** | * Active bleeding * Breast feeding |
| **Side-effects** | * Dyspepsia * Abdo pain * Diarrhoea * Bleeding disorders |
| **Interactions** | NSAIDs - increased risk of haemorrhage |
| **Elimination** | 50% urine 50% faeces |
| **Additional Notes** |  |
