| Cause of Nauea/Vomiting                         | First-line anti-emetic |
| ----------------------------------------------- | ---------------------- |
| Cerebral                                        | Cyclizine*             |
| Vestibular                                      | Cyclizine              |
| Toxic (medication, electrolytes, infection etc) | Haloperidol            |
| Gastric stasis                                  | Metaclopramide         |
| Gastroenteritis/chemotherapy                    | Ondansetron            |
| Bowel obstruction **without** colic             | Metaclopramide         |
| Bowel obstruction **with** colic                | Cyclizine/haloperidol  |
Hyoscine butylbromide can be used for relief in obstructive colic
