| **Family & Subtype** | **G-Protein** | **Primary Locations**                                            | **Key Physiologic Effects**                                                                                   | **Clinical Relevance (Example Drugs)**                                                                    |
| -------------------- | ------------- | ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **ADRENERGIC**       |               |                                                                  |                                                                                                               |                                                                                                           |
| **α1 (Alpha-1)**     | Gq            | Vascular smooth muscle, pupillary dilator muscle, prostate.      | Vasoconstriction, mydriasis (pupil dilation), prostate/bladder sphincter contraction.                         | **Agonists:** Phenylephrine (decongestant).<br><br>  <br><br>**Antagonists:** Tamsulosin (BPH), Prazosin. |
| **α2 (Alpha-2)**     | Gi            | Presynaptic nerve terminals, pancreas, platelets.                | _Inhibits_ norepinephrine release (negative feedback), inhibits insulin release.                              | **Agonists:** Clonidine (hypertension), Dexmedetomidine (sedation).                                       |
| **β1 (Beta-1)**      | Gs            | Heart, juxtaglomerular (JG) cells of kidneys.                    | $\uparrow$ Heart rate (chronotropy), $\uparrow$ contractility (inotropy), $\uparrow$ renin release.           | **Antagonists:** Metoprolol, Atenolol (beta-blockers for HTN, angina, CHF).                               |
| **β2 (Beta-2)**      | Gs            | Lungs (bronchial muscle), peripheral vasculature, liver, uterus. | Bronchodilation, vasodilation, glycogenolysis, uterine relaxation (tocolysis).                                | **Agonists:** Albuterol (asthma), Terbutaline.                                                            |
| **β3 (Beta-3)**      | Gs            | Adipose tissue, detrusor muscle of bladder.                      | Lipolysis, relaxation of the bladder (prevents voiding).                                                      | **Agonists:** Mirabegron (overactive bladder).                                                            |
| **CHOLINERGIC**      |               |                                                                  |                                                                                                               |                                                                                                           |
| **M1 (Muscarinic)**  | Gq            | CNS, enteric nervous system.                                     | Memory/cognition, regulates gastric acid secretion.                                                           | **Antagonists:** Dicyclomine (IBS), Benztropine.                                                          |
| **M2 (Muscarinic)**  | Gi            | Heart (SA and AV nodes).                                         | $\downarrow$ Heart rate, $\downarrow$ atrial contractility.                                                   | **Antagonists:** Atropine (used for bradycardia).                                                         |
| **M3 (Muscarinic)**  | Gq            | Exocrine glands, smooth muscle (GI/bladder), endothelium, eye.   | $\uparrow$ Secretions (saliva, tears), bronchoconstriction, miosis (pupil constriction), bladder contraction. | **Agonists:** Pilocarpine (glaucoma).<br><br>  <br><br>**Antagonists:** Ipratropium (COPD), Oxybutynin.   |
| **Nn (Nicotinic)**   | Ion Channel   | Autonomic ganglia, adrenal medulla.                              | Excitatory neurotransmission, epinephrine release.                                                            | **Antagonists:** Hexamethonium (obsolete clinically, historically used for HTN).                          |
| **Nm (Nicotinic)**   | Ion Channel   | Neuromuscular junction (NMJ).                                    | Skeletal muscle contraction.                                                                                  | **Antagonists:** Rocuronium, Vecuronium (paralytics for intubation).                                      |
| **DOPAMINERGIC**     |               |                                                                  |                                                                                                               |                                                                                                           |
| **D1**               | Gs            | Renal, splanchnic, and coronary vasculature.                     | Vasodilation (increases renal blood flow at low doses).                                                       | **Agonists:** Fenoldopam (hypertensive emergencies).                                                      |
| **D2**               | Gi            | CNS (striatum, pituitary).                                       | Modulates movement, inhibits prolactin release.                                                               | **Agonists:** Pramipexole (Parkinson's).<br><br>  <br><br>**Antagonists:** Haloperidol (Antipsychotic).   |
| **OTHER NOTABLE**    |               |                                                                  |                                                                                                               |                                                                                                           |
| **H1 (Histamine)**   | Gq            | Respiratory/GI smooth muscle, endothelium, CNS.                  | Bronchoconstriction, vasodilation (edema), pain/pruritus, wakefulness.                                        | **Antagonists:** Diphenhydramine (allergies, sleep), Cetirizine.                                          |
| **H2 (Histamine)**   | Gs            | Gastric parietal cells.                                          | $\uparrow$ Gastric acid secretion.                                                                            | **Antagonists:** Famotidine (GERD, ulcers).                                                               |
| **GABA-A**           | Ion Channel   | CNS.                                                             | Major inhibitory receptor; opens $Cl^-$ channels causing hyperpolarization.                                   | **Positive Modulators:** Benzodiazepines, Barbiturates, Propofol.                                         |
| **Mu (μ Opioid)**    | Gi            | CNS, GI tract.                                                   | Analgesia, euphoria, respiratory depression, constipation, miosis.                                            | **Agonists:** Morphine, Fentanyl.<br><br>  <br><br>**Antagonists:** Naloxone.                             |
