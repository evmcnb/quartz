- mild: 5.5 - 5.9 mmol/L
- moderate: 6.0 - 6.4 mmol/L
- severe: ≥ 6.5 mmol/L

## Causes

|                          |                                                                                                                                                                                |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Medications**          | ACEis  <br>ARBs  <br>Potassium sparing diuretics  <br>Trimethoprim  <br>Beta blockers  <br>Suxamethonium                                                                       |
| **Acute Conditions**     | AKI  <br>Metabolic acidosis  <br>Rhabdomyolysis  <br>[[Full/Tumour lysis syndrome\|Tumour lysis syndrome]] <br>Burns  <br>Hypoaldosteronism <br>Type IV renal tubular acidosis |
| **Pseudo-hyperkalaemia** | Test tube haemolyiss  <br>Prolonged tourniquet time  <br>Marked leucocytosis haemolysis  <br>Drip arm sample                                                                   |


## Signs

The following changes are associated with hyperkalaemia:  
- peaked or 'tall-tented' T waves (occurs first)
- loss of P waves
- broad QRS complexes
- sinusoidal wave pattern

## Management

* Treat if 6.5 mmol/L or if any ECG changes


1. Calcium gluconate - stabilize the cardiac membrane
2. [[Pearls/Insulin|Insulin]]/Dextrose infusion - drives potassium from extracellular space in (insulin) , dextrose to prevent [[Full/Hypoglycaemia]] when [[Pearls/Insulin|Insulin]] is given. Consider nebulised salbutamol
3. Calcium resonium - remove potassium from the body (enemas are better than oral). Dialysis in persistent hyperkalaemia in AKI
4. Stop exacerbating drugs e.g. ACE inhibitors, loop diruetics
