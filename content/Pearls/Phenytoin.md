| **Drug Class**         | Anti-convulsant                                                                                                                                                                                                                                                                                              |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Mechanism**          | Alters transmembrane movement of Na+/K+ by blocking voltage-gated Na+ channels - prevents spread of epileptic discharges                                                                                                                                                                                     |
| **Typical Dose**       | 3-4mg/kg daily                                                                                                                                                                                                                                                                                               |
| **Indications**        | - [[Pearls/Epilepsy\|Epilepsy]] all except absence seizure <br>- Trigeminal neuralgia                                                                                                                                                                                                                        |
| **Contra-indications** | Acute porphyrias                                                                                                                                                                                                                                                                                             |
| **Side-effects**       | Common: dizziness, headache, confusion, insomnia, nausea, vomiting, hirsutism  Rarely: **gum hypertrophy**, rash, [[Pearls/Steven-Johnson Syndrome\|Steven-Johnson Syndrome]], drug-induced SLE                                                                                                              |
| **Interactions**       | Induces hepatic drug-metabolising enzymes:  <br>- [[Pearls/Amiodarone\|Amiodarone]]<br>- Aspirin<br>- cimetidine<br>- diltazem, nifedipine <br>- OCP - increased metabolism of OCP <br>- Any [[Pearls/Cytochrome P450 dependant drugs\|Cytochrome P450 dependant drugs]] (inc [[Pearls/Warfarin\|Warfarin]]) |
| **Elimination**        |                                                                                                                                                                                                                                                                                                              |
| **Additional Notes**   | Zero order kinetics. Binds to albumin. If albumin becomes saturated levels spike                                                                                                                                                                                                                             |

Really annoying to give. If diluted can crystalize out so lines need filters. Zero order kinetics. Lots of toxic effects. Narrow therapeutic range which is hard to control. It binds to albumin, but once this is saturated the free levels can suddenly spike causing toxicity
